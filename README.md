# Orphanage Management System

A web-based application built with PHP and MySQL for managing orphanage operations —
user registration, bookings, staff management, and an admin dashboard.

## Features

- User registration and login
- Admin dashboard for managing records
- Booking system for visitors/services
- Employee (staff) management
- Contact and enquiry forms

## Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Dependencies:** Composer

├── about.php # About page
├── service.php # Services page

## Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/underrated-human/BCA-mini-project.git
Import the database

Open phpMyAdmin (or the MySQL CLI)

Create a database named orphanage_db

Import orphanage_db.sql

Configure the database connection

Copy db.example.php to db.php

Fill in your host, username, password, and database name

Run the project

Place the project folder inside htdocs/ (XAMPP) or www/ (WAMP)

Start Apache and MySQL

Open http://localhost/orphanage in your browser

# Orphanage Management System

A web-based application built with PHP and MySQL for managing orphanage
operations — user registration, bookings, staff records, and an admin
dashboard. Developed as a BCA mini project.

## Features

- User registration and login
- Admin dashboard for managing records
- Booking system
- Employee / staff management
- Contact and enquiry form
- Public pages (home, about, services)

## Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript

## Project Structure
